# chat-server
A simple solution for communication, specifically on the same network

## features
The ability to host and connect to servers, with basic commands, and some admin commands

## prerequisites
- Go 1.26.5 or higher

## installation
go install:
````bash
go install github.com/sofinetimarian/chat-server@latest
````
clone it:
````bash
git clone https://github.com/sofinetimarian/chat-server
cd chat-server
````
